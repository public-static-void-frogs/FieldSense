# Опис колонок: датасет `csb_bounds` (результат `csb_bounds.py`)

Один рядок = один полігон CSB (Crop Sequence Boundaries, NASS), для якого за центроїдом і площею оцінено обмежувальний прямокутник (bounding box).

> **Важливо:** `min_*`/`max_*` — це **оцінка**, а не реальний контур поля. Прямокутник побудовано навколо центроїда з тією самою площею, що й у поля (для `--shape circle` — з площею, більшою у 4/π ≈ 1,27 раза), орієнтований за сторонами світу, без повороту. Реальний полігон нерегулярний і може виходити за межі цього прямокутника або займати лише його частину. Для точних меж використовуйте `ingest --keep-geometry`.

| Колонка | Тип | Походження | Опис |
|---|---|---|---|
| `CSBID` | рядок | NASS | Ідентифікатор полігона. Символи 1–2: FIPS штату; 3–4: останні дві цифри початкового року; 5–6: останні дві цифри кінцевого року; останні 9: порядковий номер. |
| `centroid_lon` | float | скрипт `ingest` | Довгота (WGS84, градуси) геометричного центроїда полігона. У увігнутих полігонах центроїд може лежати поза полігоном. |
| `centroid_lat` | float | скрипт `ingest` | Широта (WGS84, градуси) центроїда. |
| `area_acres` | число | NASS (`CSBACRES`) | Площа полігона в акрах (1 акр = 0,404686 га = 4046,86 м²). Зберігається як ціле число, тому для дуже малих полігонів округлення помітне. |
| `bbox_width_m` | float | скрипт `csb_bounds` | Ширина оціночного прямокутника у метрах (схід–захід) в рівновеликій проєкції EPSG:5070. Для `--shape square` і `--aspect 1` дорівнює √(площа в м²). |
| `bbox_height_m` | float | скрипт `csb_bounds` | Висота оціночного прямокутника у метрах (північ–південь). `ширина / висота = --aspect`. |
| `min_lon` | float | скрипт `csb_bounds` | Західна межа прямокутника, довгота (WGS84). |
| `min_lat` | float | скрипт `csb_bounds` | Південна межа прямокутника, широта (WGS84). |
| `max_lon` | float | скрипт `csb_bounds` | Східна межа прямокутника, довгота (WGS84). |
| `max_lat` | float | скрипт `csb_bounds` | Північна межа прямокутника, широта (WGS84). |
| `STATEFIPS` | рядок | NASS | FIPS-код штату (2 цифри). |
| `CNTYFIPS` | рядок | NASS | FIPS-код округу (5 цифр, включає штат). |
| `CNTY` | рядок | NASS | Назва округу. |

## Примітки

- Усі координати в колонках `centroid_*`, `min_*`, `max_*` — WGS84 у градусах (EPSG:4326), округлені до 6 знаків (≈ 0,1 м).
- Прямокутник будується в EPSG:5070 (Albers Equal Area, метри) і лише потім переводиться в lon/lat; кути переводяться окремо, тому в градусах він трохи відрізняється від ідеального квадрата (на масштабі поля різниця незначна).
- Центр прямокутника за замовчуванням — `centroid_lon/lat`; з `--centre inside` це `INSIDE_X/INSIDE_Y` від NASS (одиниці вимірювання в метаданих прямо не вказані, імовірно метри в проєкції шару).
- Додаткові колонки (`CDLyyyy`, `STATEASD` тощо) з'являються лише якщо їх передано через `--keep`.
- Опис колонок самих CSB: див. `csb_columns.md`.
