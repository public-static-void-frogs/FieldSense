## (B) Errors, overclaims, gaps in the team docs

1. **Blank spot, biggest issue: neither doc names any source for soil nutrients, fertiliser, yields, crop calendars, or soil-carbon modelling.** The Data Guide stack (POWER, SMAP, IMERG, HLS, NEX, WorldCover/SoilGrids, AppEEARS) supports climate + vegetation only. Function 2 (soil-depletion reconstruction) has zero data/model coverage.
2. **No global crop-type source.** Crop history is anchored on CDL (US-only). For a non-US (Ukraine) farmer the only fallback listed is "HLS NDVI crop-group clustering" with no labels, no training data, no method. WorldCover is called a "global cropland mask" but it is two non-comparable single-year maps (2020, 2021) with no crop types.
3. **POWER resolution and start year.** Report says ~0.5 x 0.625 deg (correct for met). Missing: solar is 1 x 1 deg CERES, from 1984. Data Guide's "daily meteorology from 1981, solar from 1984" is right, but the report architecture box says "POWER daily 1991-present" (inconsistent; use 1981). The report also says "36+ years" (fine). Also not mentioned: CERES processing delay since Aug 2024 is degrading POWER's recent solar series [V].
4. **SMAP product labelling.** Data Guide calls SPL4SMGP "root-zone is the key irrigation and drought signal" at 9 km; it is a model product (Catchment LSM + assimilated radiometer Tb), has no irrigation representation, and is 3-hourly 9 km. Cheat sheet row "SMAP L3/L4, 9-36 km, daily/3-hourly" merges three products (SPL3SMP 36 km, SPL3SMP_E 9 km, SPL4SMGP 9 km): split them. Report 4.1E says Crop-CASMA serves "9 km root zone, 1 km surface": the 1 km is a derived MODIS-LST downscaling (CONUS only), not a SMAP-native product. Data Guide's table lists "SMAP L3 (SPL3SMP_E) enhanced" correctly as 9 km, but the claim "observation-based alternative to model-based L4" ignores that L3 is surface only. New 2026 caveat: reprocessing for 14 May-28 Jul 2026 [V].
5. **NISAR status stale.** Data Guide says "could not confirm". Now: calibrated/provisional L-band public since 20 Jul 2026 (obs from 17 Jun 2026) [V]; report says "launched 30 July 2025" (correct) and ~200 m SM (correct as design spec, still "coming soon"/provisional in the catalogue). Both overstate its usefulness: there is no historical record, so it cannot reconstruct past seasons.
6. **MODIS cadence/availability.** "250 m-500 m NDVI/EVI composites every 8-16 days": MOD13Q1/MYD13Q1 are 16-day; Terra+Aqua are being decommissioned (late 2026/early 2027) [V]. Data Guide "Mission status" note only mentions Challenge 1. MOD16/MOD17/MOD11 inherit the same risk.
7. **ECOSTRESS.** Data Guide #9 "70 m ET and evaporative stress" lists no version; V1 ET (ECO3ETALEXI) was decommissioned 30 Jan 2026 [V]. Report G conflates 70 m ECOSTRESS ESI (CONUS) and global 5 km ALEXI ESI correctly, but the Data Guide's "field-level crop water stress" is overstated: irregular, clear-sky only, ~2018+.
8. **HLS.** Doc claim "most-downloaded NASA product in FY2024" not verified here [U]. Missing key spec: start dates (HLSL30 2013, HLSS30 late 2015) set the maximum depth of any history reconstruction. Latency 1.7-4 days depending on source. Report H says "2-3 days revisit" (ok for combined L+S).
9. **IMERG.** "2000 to present" correct (Jun 2000). Missing: Final latency 3.5 months; V06/V07 not mixable. Data Guide size estimate "100-200 GB/yr" not verified.
10. **GRACE.** Data Guide labels "GRACE-FO groundwater and soil moisture drought indicators ... 0.25 deg" as if 0.25 deg were the real resolution; actual GRACE resolution is hundreds of km. The product also begins 2003 (GRACE), not just GRACE-FO (2018). Cheat sheet's "GRACE-FO mascons, PO.DAAC" is a different dataset than the UNL data-assimilation product listed in the guide.
11. **OpenET coverage** inconsistent: Data Guide "US West" vs report "contiguous US". Neither flags that it is useless for non-US fields.
12. **Soil-depletion metrics doc is not a data plan.** It lists lab/field-measured indicators (bulk density, aggregate stability, enzymes, earthworms, MBC, CASH/SMAF/SQI scoring) that cannot be derived from satellites for a field polygon. No mapping to available data (SoilGrids, WoSIS, HWSD, climate). The only remotely-obtainable ones are SOC (static maps), texture, pH, N/P/K coarse maps; trends must come from a model (RothC) plus a nutrient mass balance, not from the indices. Index scores also depend on region-specific reference databases (Cornell: Northeast US).
13. **NEX-GDDP-CMIP6 model count:** report says 35 models; GEE catalog (v1.0/1.1) lists 34. Check v2.0 (May 2025 tech note) count before quoting. Not for hindcasts.
14. **CDL**: Data Guide "30 m" (outdated since 2024: now 10 m) and start year not given (CONUS 2008).
15. **SoilGrids:** presented as a "soil context" (fine) but not flagged as static and highly uncertain; carbon stock layers exist only for 0-30 cm. Data Guide link for ISRIC uses soilgrids.org (OK).
16. Minor: report architecture lists "POWER ET0" as an input; POWER provides the meteorological inputs, ET0 has to be computed (FAO-56 Penman-Monteith) [U on whether an ET0 parameter is offered].
17. **Futures:** neither doc contains a futures source.

## (D) Recommended minimal stack (about 2 weeks of work)

**Principle:** use free, keyless/low-friction, global sources; make every output carry a confidence flag; do not claim more than data support.

1. **Field input:** user polygon (+ optional FTW/fiboa polygons for snap and validation).
2. **Crop history (function 1):**
   - Time series: Sentinel-2 L2A via CDSE STAC (10 m, 2016-) as primary; HLS (30 m, 2013/2015-) or Landsat as fallback for deeper years. Sentinel-1 only if time permits (cloud-free dates, cereal vs row crop).
   - Priors/labels: WorldCereal 2021 (global), EU Crop Map 2022 (covers Ukraine), CDL (US), GLAD cropland 2003-2019, Dynamic World (cropland presence); WorldCereal reference data points for a small classifier.
   - Human-in-loop: farmer confirms/overrides each season. Present result as "likely crop group" (winter cereal / spring cereal / maize-sunflower-soy / oilseed rape / fallow) with confidence, not exact crop.
3. **Soil-depletion reconstruction (function 2):** model not metrics.
   - Initial state: SoilGrids 2.0 (clay, SOC, pH; use quantile uncertainty), sanity-check with WoSIS nearest profiles and HWSD v2.
   - Drivers: climate from AgERA5/ERA5-Land (primary) or POWER (keyless fallback); annual yield proxy from SPAM2020/GDHY/FAOSTAT yield (country) scaled by NDVI anomaly.
   - Mechanism: RothC (SOC) + simple nutrient balance: removals = yield x FAOSTAT/Ludemann coefficient; inputs = IFA FUBC rates (or FAOSTAT country default) + BNF for legumes + deposition.
   - Output: SOC trend with an uncertainty band and N/P/K balance per season, labelled "modelled estimate". Benchmark against GSOCseq scenario deltas. Retain only measurable indicators from the metrics doc (SOC, pH, texture, available N-P-K) as optional manual lab inputs.
4. **Rotation recommendation (function 3):** NEX-GDDP-CMIP6 (2040 precomputed per region, bias-corrected against ERA5/POWER baseline), GAEZ v5 suitability, Sacks/WorldCereal crop calendars, rules for host-family return intervals and legume slots, water balance from POWER/AgERA5 + IMERG.
